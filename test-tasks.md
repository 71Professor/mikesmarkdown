# Task Test

## Normale Liste (mit Bullet Points sichtbar)
- Punkt 1
- Punkt 2
- Punkt 3

## Task Liste (ohne Bullet Points, nur Checkboxen)
- [ ] Erste Aufgabe
- [ ] Zweite Aufgabe
- [x] Dritte Aufgabe (erledigt)
- [ ] Vierte Aufgabe

## Gemischte Liste
- Normaler Punkt
- [ ] Task in der Mitte
- Noch ein Punkt
- [x] Erledigte Task

## Das funktioniert NICHT (fehlendes `-`)
[ ] Diese Task wird nicht erkannt
[ ] Weil das Minus fehlt
